# 🚴‍♂️ Bike Sales Interactive Excel Dashboard

## 📌 Project Overview
This project features an interactive Excel data dashboard built to analyze customer purchasing behavior and key trends for a bike retail dataset. The objective is to convert raw demographic and transactional data into actionable business insights that help identify target customer profiles and sales opportunities.

---

## 🔍 Key Insights & Business Observations
* **Income & Gender Dynamics:** Higher-income brackets correlate significantly with increased bike purchasing frequency, with male customers showing a slightly higher conversion rate in middle-income segments.
* **Commute Distance Factor:** Customers living within a 0–1 mile commute radius represent the primary purchasing demographic, suggesting that proximity or short-distance commuting drives necessity.
* **Age Group Segments:** The "Middle Aged" demographic (35–54) forms the core customer base, dramatically outperforming both the adolescent and senior markets.

---

## 🛠️ Features & Technical Excel Skills Used
* **Data Cleaning & ETL:** Handled missing values, formatted currency/date attributes, and created custom helper columns (e.g., nesting conditional logic to group raw ages into `Age Brackets` like Young, Middle-Aged, and Senior).
* **Pivot Tables & Advanced Aggregations:** Aggregated raw rows to extract averages, counts, and sums across multi-layered categories.
* **Dynamic Slicers & Timelines:** Implemented interactive filtering across Region, Education, and Marital Status, allowing stakeholders to slice the entire view on the fly.
* **Data Visualization:** Deployed coordinated, clean chart types (Clustered Bar Charts, Line Charts) utilizing a consistent, distraction-free color palette.

---

## 🚀 How to Interact with the Project
1. Download the `Bikes Sales.xlsb` file from this repository.
2. Open it using Microsoft Excel.
3. Make sure to **Enable Macros/Content** if prompted, and use the left-hand **Slicers** to dynamically filter the sales charts!
